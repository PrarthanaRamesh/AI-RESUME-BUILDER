AI Resume Builder
An AI-powered Resume Builder built with Streamlit and Google's Gemini API. This application allows users to enter their professional details, generate polished resume content using AI, and download the final resume as a DOCX file.

Features
* AI-generated professional resume content
* Clean and interactive Streamlit interface
* Generates:
  * Professional Summary
  * Work Experience
  * Education
  * Skills
* Download resume as a Microsoft Word (.docx) file
* Uses Google's Gemini AI model for content generation

Tech Stack:
* Python 3.11
* Streamlit
* Google Gemini API
* python-docx
* python-dotenv
